# 前后端整合说明

## 结构

```text
H:\karin-admin\

└── backend\    # Spring Boot
```

## 登录流程

1. 打开 `/login`
2. 浏览器 `POST {API}/api/auth/login`
3. 成功后把 JWT 与用户信息写入 `localStorage`
4. `AuthGuard` 保护后台路由
5. 请求受保护接口时带 `Authorization: Bearer <token>`
6. 可用 `GET /api/users/me` 刷新当前用户
